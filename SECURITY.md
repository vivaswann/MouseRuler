# Security

Do not post credentials or private diagnostics in public issues. Use GitHub's
private vulnerability reporting if the repository enables it. Otherwise contact
the maintainer through their GitHub profile before disclosing exploitable details.

MouseMeasure reads relative mouse reports, confines the pointer only during
recording, and stores settings locally. It does not upload measurement data.
Report cursor-release defects promptly with a minimal reproduction and Windows
version. Escape cancels a recording; switching applications releases the cursor.
